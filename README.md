# Data Analysis

## Project Overview

This project focuses on cleaning and preparing multiple dirty datasets for analysis , and analysing them.

## Dataset Information

- **Source:** [
  https://www.kaggle.com/datasets/ahmedmohamed2003/cafe-sales-dirty-data-for-cleaning-training ,
  https://www.kaggle.com/datasets/carlosparadis/fires-from-space-australia-and-new-zeland ,
  https://www.kaggle.com/datasets/amruthayenikonda/dirty-dataset-to-practice-data-cleaning
  ]

> **Note:** The raw datasets are excluded from this repository via `.gitignore` to keep the project lightweight. Download the raw file from the source link above and place it in `data_sets before running the cleaning scripts.
